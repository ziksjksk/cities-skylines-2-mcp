# MCP tool reference

## Shared contract

The server uses MCP stdio. Tools that read or mutate the game call the localhost bridge at `CS2_BRIDGE_URL` (default `http://127.0.0.1:8642`). Coordinates are CS2 world `x/z` meters with optional `y` elevation. Entity ids are `{index, version}` pairs returned by the game.

Mutation tools should be called in this order:

```text
cs2_capabilities -> cs2_discover_assets -> preview/dryRun -> execute -> cs2_validate_city
```

Successful planning is not construction evidence. A construction result must contain the bridge response for each native operation. Bridge failures use a machine-readable `success:false`, `noSuccess:true`, `error.message`, optional HTTP `status`/payload, and `recommendedAction`; planner failures use `success:false` and structured `code`, `severity`, `message`, and `recommendedAction` issue entries where applicable.

| `cs2_list_zones` | List runtime zone prefab names. | none | zone entries | no city | `cs2_list_zones()` |

| `cs2_demolish` | Delete one building, road edge, tree/plant, or district through the native bulldozer pipeline. | `index`, `version` | native deletion request plus exact entity-absence readback | stale/non-deletable entity; deletion already pending; readback timeout | `cs2_demolish({index:42,version:1})` |
| `cs2_create_district` | Create and verify a district polygon through the native area definition path. | `nodes` as `x,z;x,z;...`, optional `prefab`, `execute`, `dryRun` | default native execution plus new district entity readback, or non-mutating preview | invalid polygon; no district prefab; concurrent operation; missing readback | `cs2_create_district({nodes:"0,0;500,0;500,400;0,400",execute:false})` |

| Tool | Purpose | Parameters | Return | Errors/limitations | Example |
|---|---|---|---|---|---|
| `cs2_capabilities` | Read the live native capability contract. | none | booleans, details, game/mod version, mode | bridge unreachable | `cs2_capabilities()` |
| `cs2_coordinate_info` | Read shared axes, units, bounds, terrain and paging conventions. | none | coordinate contract | bridge unreachable | `cs2_coordinate_info()` |

## Recommended autonomous sequence

```text
cs2_ping
cs2_capabilities
cs2_coordinate_info
cs2_discover_assets
cs2_analyze_map
cs2_query_utilities
cs2_plan_metropolis
cs2_plan_road_network / cs2_build_interchange(dryRun=true)
cs2_run_autonomous_city_cycle(execute=false)
cs2_run_autonomous_city_cycle(execute=true, maxSegments=bounded value, runSimulationHours=non-zero)
cs2_validate_city(includeScreenshots=true)
cs2_run_simulation
cs2_analyze_city
cs2_optimize_traffic
```

The sequence is intentionally iterative. A plan is not an excuse to build the entire map in one unverified batch.
